# Diagrams

## Purpose

The diagrams that explain this portfolio are Mermaid blocks inside the English and Spanish documents. GitHub renders those blocks. This directory is reserved for an exported image when a document needs one that Mermaid cannot express.

Do not add an image that only repeats a Mermaid diagram already in the docs. If an image is added, commit the source next to it and link it from both language versions.
