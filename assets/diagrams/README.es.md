# Diagramas

## Propósito

Los diagramas que explican este portafolio son bloques Mermaid dentro de los documentos en inglés y en español. GitHub renderiza esos bloques. Este directorio queda reservado para una imagen exportada cuando un documento necesite una que Mermaid no pueda expresar.

No hay que agregar una imagen que solo repita un diagrama Mermaid que ya está en la documentación. Si se agrega una imagen, el fuente va al lado y el enlace aparece en las dos versiones de idioma.
